# Waypoint+ Fuel Station & Convenience Store Website

A responsive multi-page HTML/CSS/JavaScript website concept.

## Pages
- `index.html` — Home1
- `home2.html` — Home2 (full-bleed hero layout)
- `about.html`
- `services.html`
- `offers.html`
- `products.html` — fuel grades, motor oils, fresh coffee, bakery, and market catalog
- `contact.html` — includes Google Maps embed and social links
- `login.html`, `register.html`, `forgot-password.html` — standalone authentication screens

## Run locally
Open `index.html` in a modern browser. No build tools or server are required.

## Included interactions
- Responsive navigation menu with RTL, theme, and Sign In inside the mobile/tablet menu
- RTL/LTR toggle
- Light/dark theme toggle with saved preference
- Password visibility eye toggle and back-to-top button
- Demo form feedback for contact and authentication forms

## Before production
This is a front-end concept only. Authentication and form submissions are demo interactions and do not connect to a backend. Replace sample contact details, map location, offer content and social URLs with your real business information. Photos are loaded from Unsplash image URLs, so an internet connection is required to display them. Review image licensing/usage and replace with approved brand assets before commercial launch.
